# Grid AI - AI-Powered Platform for Remote Work Collaboration

[Live Demo](https://remote-work-collaboration-masl.vercel.app/) • Built with ❤️ using **Clerk**, **Stream**, **Cohere**, **Node.js**, **React.js**, and **Next.js**

---

## 🚀 Overview

**Grid AI** is a modern remote collaboration platform powered by AI. It streamlines virtual meetings with smart scheduling, real-time video conferencing, and intelligent AI enhancements — all accessible through a clean and intuitive interface.

---

## ✨ Key Features

### 🔐 User Authentication
- Secure sign-in and sign-up using **Clerk**
- Email/password authentication
- Development mode indicator for testing

### 📅 Meeting Management
- **Personal Meeting Room** with a persistent link and unique ID
- **Schedule Meetings** with date & time selection
- **Join Meetings** quickly via link
- **Meeting History** with call logs and timestamps

### 🤖 AI-Enhanced Capabilities
- Instant video calls powered by **Stream**
- AI-generated **live captions** using **Cohere NLP**

### 🖥️ User Interface
- Sleek dashboard showing upcoming and past meetings
- Integrated weather display
- Easy navigation: Home, Upcoming, Previous, Recordings, Personal Room

- **Frontend**: React.js, Next.js
- **Backend**: Node.js
- **Authentication**: Clerk
- **Video Conferencing**: Stream
- **AI/NLP**: Cohere
